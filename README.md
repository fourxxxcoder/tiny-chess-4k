A chess engine in under 4 KB of Python: full legal move generation, negamax alpha-beta search with quiescence, a transposition table, null-move pruning and piece-square-table evaluation, playing the make.fun gauntlet over HTTP under a fixed node budget (never a clock, so every run is deterministic).

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
